## Featured Projects

### 1. [AI Photography Archive](https://github.com/shangkejin2002/ai-photography-archive)

写真のアップロードからメタデータ整理、AI による画像理解、自然言語での写真選定、Portfolio の公開までを一つの流れにまとめた、個人向けの Web Application です。設計・実装に加えてデプロイまで行い、現在 Web 上で公開しています。

**Tech:** React / TypeScript / Umi / Ant Design · Java / Spring Boot / REST API · MySQL · DeepSeek API

- JPEG / PNG のアップロードと、EXIF・GPS・撮影情報の抽出
- AI による画像説明・視覚タグの生成と、自然言語による写真選定
- 写真の並び順や表紙を編集できる Portfolio、公開リンク、PDF 出力
- CSS 3D を用いた Story 表示と、撮影傾向を可視化する Shooting Insights
- 日本語・中国語 UI、Session 認証、ユーザー単位のデータ分離、Web へのデプロイ

[Repository](https://github.com/shangkejin2002/ai-photography-archive) · [Live Application](https://kejinphotoarchive.com/)

### 2. [Digital Financial Inclusion and Food Consumption in China](https://github.com/shangkejin2002/digital-finance-household-consumption-analysis)

卒業論文「デジタル金融包摂が中国の食料消費に与える影響」をもとにしたデータ分析プロジェクトです。CFPS の 2014 年・2018 年の家計データと省別デジタル金融包摂指数（DFI）を結合し、家計のエンゲル係数との関係を分析しました。

**Tech:** R / tidyverse / fixest / ggplot2

- データの整理・結合とロング形式への変換
- 世帯固定効果・年次固定効果を考慮した Difference-in-Differences（DID）推定
- 連続 DFI モデルと二値化モデルの比較、分析結果の可視化

[Repository](https://github.com/shangkejin2002/digital-finance-household-consumption-analysis)
